# Guide Utilisateur - Panel d'Administration

## Connexion

Rendez-vous sur l'URL du panel admin et connectez-vous avec vos identifiants.

## Gestion des Projets

### Créer un nouveau projet

1. Cliquer sur "Projets" dans le menu
2. Cliquer sur "+ Nouveau projet"
3. Remplir tous les champs obligatoires :
   - Titre du projet
   - Nom du client (peut être masqué)
   - Description courte (max 200 caractères)
   - Description détaillée
   - Upload des images
   - Sélection des technologies
   - Durée et taille d'équipe
4. Cliquer sur "Enregistrer"

### Modifier un projet

1. Dans la liste des projets, cliquer sur "Modifier"
2. Effectuer les modifications
3. Cliquer sur "Enregistrer"

### Supprimer un projet

1. Cliquer sur "Supprimer" (confirmation requise)

## Gestion des Technologies

Permet d'ajouter, modifier ou supprimer les technologies affichées sur le site.

## Gestion des Témoignages

Permet d'ajouter des témoignages clients avec possibilité de les lier à un projet spécifique.

## Gestion des Contacts

Visualisez et gérez les demandes de contact reçues via le formulaire.
- Marquer comme lu
- Archiver
- Supprimer
